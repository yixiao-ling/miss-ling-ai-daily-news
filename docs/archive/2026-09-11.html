This is a rare window into how leading vendors engineer their agents: system prompts reveal real-world tool-calling protocols, refusal policies, context management and role boundaries — essentially reverse-engineered "official best practices." Product builders can calibrate their own agent prompt architecture and guardrails; algorithm folks can study instruction constraints and the adversarial surface of jailbreaks/prompt injection. It is also a security warning: leaked prompts enable targeted attacks, which argues for pushing critical constraints down into code and model layers rather than relying on prompts alone.
