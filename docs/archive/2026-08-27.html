IQ Routing 是一款推出于 Product Hunt 的 LLM 路由工具，通过轨迹感知（trajectory-aware）技术，在 Agent 运行过程中智能分配不同模型来处理不同任务，从而显著降低推理成本。其核心思路是让低成本小模型处理简单步骤，仅在关键复杂节点调用高性能大模型。 IQ Routing is a Product Hunt launch offering trajectory-aware LLM routing that lowers agent inference costs. Instead of routing individual requests, it analyzes the full trajectory of multi-step agent execution and assigns low-cost smaller models to simple steps, reserving high-performance frontier models only for critical, quality-sensitive steps. This balances output quality against cost.

从 AI builder 视角看，IQ Routing 代表了 LLM 成本优化的一个重要方向：把"路由"从单次请求级别（如传统 route 到不同模型的单轮问答）升级为 Agent 多步执行轨迹级别。这意味着算法上需要理解 Agent 的完整执行路径——哪些步骤影响最终结果质量、哪些属于可退化的中间步骤，从而在保质量前提下用便宜模型替代昂贵模型。这对产品团队的价值直接体现在推理账单和 Agent 的规模化能力上，是当前 LLM 应用降本增效的关键抓手。其难点在于轨迹中质量敏感点的识别与路由策略的动态学习。
From an AI builder's perspective, IQ Routing represents a key evolution in LLM cost optimization: upgrading routing from single-request level to multi-step agent trajectory level. The algorithmic challenge is understanding which steps in a trajectory materially affect final output quality versus which are degradable intermediate steps, then dynamically substituting cheaper models without noticeable quality loss. For product teams, the direct payoff is a lower inference bill and greater scalability of agent-based products. The hard part lies in identifying quality-sensitive points along the trajectory and learning the routing policy. This is a meaningful lever for cost reduction in real LLM applications today.
